Device safety
  • Attendance logs are never deleted automatically. Only the main administrator can clear them (device page → Maintenance), and only after every record is confirmed in the portal. Erasing all device data and power-off are blocked in code.
  • Users are removed from devices only when you delete an employee with “portal and all devices” – just that person (ID and name must match), with a backup for Restore.
  • Existing users are only updated when name, card or password differ; device privileges are never lowered.
  • Fingerprints are only added to devices; existing fingerprints are kept.
  • Use “Write protection” on a device to make it strictly read-only.
