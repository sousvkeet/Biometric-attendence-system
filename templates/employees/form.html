How registration works
  1. Save the employee here. {% if settings_obj.push_on_employee_save %}The portal then adds them to every active device automatically.{% else %}Then use “Send to devices”.{% endif %}
  2. Enroll the fingerprint: either on the device itself (Menu → User Mgt → edit user → Fingerprint), or with Remote enrollment on the employee page.
  3. The next user sync copies the fingerprint to all other devices.

The device keeps only the first 24 characters of the name. Removing or deactivating an employee never deletes them from a device.
