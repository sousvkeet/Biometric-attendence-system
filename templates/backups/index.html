Restoring from the command line
  1. Stop the portal (Ctrl+C on ./run.sh, or pm2 stop all).
  2. Run one of: 
    .venv/bin/python manage.py restore_backup --destination "NAME" --list
.venv/bin/python manage.py restore_backup --destination "NAME" --latest
.venv/bin/python manage.py restore_backup /path/to/bioattend-backup-….gz.enc
  3. Start the portal again.

The file is verified first and a safety copy of the current database is kept in var/backups/pre-restore/. Encrypted backups need the passphrase.
