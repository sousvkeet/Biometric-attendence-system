Local folder – a folder on this computer or a mounted network drive (e.g. /mnt/nas/bioattend). Keep a second, off-site destination too.
Amazon S3 – bucket + access key with s3:PutObject, s3:ListBucket, s3:GetObject, s3:DeleteObject.

S3-compatible – also fill Endpoint URL: Wasabi https://s3.wasabisys.com, Backblaze B2 https://s3.<region>.backblazeb2.com, DigitalOcean https://<region>.digitaloceanspaces.com, Cloudflare R2 https://<account>.r2.cloudflarestorage.com, MinIO http://host:9000.
FTP – plain FTP sends the password unencrypted; prefer FTPS or SFTP when the server supports it. Default port 21.
FTPS – FTP with TLS (explicit, port 21). Untick “Verify TLS certificate” only for servers with a self-signed certificate.
SFTP – SSH file transfer (port 22) with a password or a private key. The server's key is remembered on the first connection and checked every time after.
rclone – one connector for 70+ providers: Google Drive, OneDrive, Dropbox, Box, Mega, pCloud, Azure Blob, Google Cloud Storage, Backblaze, Yandex and more.
  1. On any computer with a browser, install rclone and run rclone config → n (new remote), give it a name (e.g. gdrive) and follow the login steps.
  2. Run rclone config show gdrive and paste the output (starting with [gdrive]) into rclone config.
  3. Enter the same name as remote name and a folder, e.g. Backups/BioAttend.
The config (with its login token) is stored encrypted; refreshed tokens are saved automatically. For Google Drive, scope = drive.file limits rclone to files it created.
WebDAV – Nextcloud/ownCloud: https://cloud.example.com/remote.php/dav/files/USERNAME/ with an app password. Synology: https://nas:5006/.

Retention only ever removes files named bioattend-backup-… created by this system.
